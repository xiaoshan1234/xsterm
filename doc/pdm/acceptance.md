每条都对应一个可执行的验证方法。CI 跑得过的标 ✅，需手动验证的标 🔍。

A. TUI 兼容性（最重要，P0）
================================================================

✅ vttest 自动测试套件（vttest.exe）
   - 通过率 ≥ 90%

   - 解析路径：xterm.js + xterm-addon-unicode11

🔍 vim 基础
   - 启动 vim，输入 :version 显示 24-bit color（`+termguicolors`）
   - 鼠标拖选、滚轮滚动、滚轮切换 buffer 都正常
   - 退出后终端回到正常 prompt，无残留

🔍 lazygit
   - 状态颜色正确（绿/红/黄）

🔍 htop / btop / k9s / fzf
   - 颜色 + 鼠标 + 滚动全部正常
   - 退出后无残留

🔍 Kitty graphics protocol
   - 运行 https://github.com/kovidgoyal/kitty/tree/master/tools 下的图像测试
   - 图像正确显示

🔍 Unicode
   - 中文 / emoji / ZWJ 序列宽度正确（每个 CJK = 2 列，emoji = 2 列）
   - 阿拉伯文连字正确（如果有 RTL 测试）

🔍 性能
   - `cat 1GB.log` 时滚动不卡（流式渲染）
   - `yes | head -n 100000` 不 OOM
   - 100 个标签页只开 5 个时内存 < 200MB（任务管理器查看）

================================================================
B. MCP server（P0）
================================================================

✅ MCP 协议兼容性
   - 用 rmcp 自带测试 client 连接 → 列出所有工具
   - 每个工具调用一次成功

✅ list_sessions
   - 启动 3 个标签页 → 工具返回 3 个 session

✅ create_session
   - 调用 → 新标签页出现 → 返回 session_id

✅ send_keys
   - 创建 session → send_keys("echo hello\n") → capture_screen 看到 "hello"
   - send_keys(["Ctrl", "C"]) → 当前命令被取消

✅ subscribe_output
   - 长输出命令（如 `find /`）持续产生输出 → 客户端订阅收到增量
   - 不丢不重（用序号校验）

✅ attach_session / detach_session
   - attach 后用户键盘输入不进入 PTY
   - UI 顶部出现 banner
   - detach 后恢复正常

✅ wait_for
   - 在 long-running 命令后调用 wait_for(pattern="READY", timeout=10)
   - 输出匹配时立即返回
   - 超时返回明确错误

✅ TCP 模式（可选）
   - 默认关闭，配置开启后只能监听 127.0.0.1
   - 无 token 请求被拒（401）

🔍 Claude Desktop 端到端
   - 配置 stdio MCP server
   - 重启 Claude Desktop，看到工具列表
   - 让 Claude "在终端里运行 ls" → 真的运行并返回结果

🔍 Cursor / Codex 端到端
   - 同上

C. 复制粘贴（P0）
================================================================

🔍 选中即复制
   - 鼠标左键拖选一段文字 → 粘贴到记事本看到内容

🔍 多行粘贴检测
   - 复制 3 行文本 → 粘贴 → 弹确认提示
   - 选"粘贴" → 内容进入
   - 选"取消" → 不进入

🔍 Bracketed paste
   - 复制多行 → 在 nano / vim 中粘贴 → 不触发意外命令
   - 在 raw mode 下能看到 \x1b[200~ ... \x1b[201~ 包裹

🔍 自动 trim
   - 复制带首尾空行 → 粘贴 → 空行被移除

🔍 ANSI 剥离
   - 复制带颜色代码 → 在 vim insert 模式粘贴 → 只看到文本

🔍 路径 / URL 检测
   - 选中 http://... → 悬浮按钮出现 → 点击 → 浏览器打开
   - 选中 C:\Users\... → 悬浮按钮 → 点击 → 资源管理器打开

================================================================

✅ 默认无网络监听
   - 应用启动后 `netstat -ano | findstr LISTEN` 不应看到 xsterm.exe（除非 TCP MCP 启用）
