# AI Terminal — 合规清单

按法规 / 平台 / 安全 / 开源 / 用户分层，逐条对应实现 / 文档位置。

================================================================
一、Microsoft Store 合规（P0）
================================================================

[ ] 1.1 隐私政策
    - 独立 URL（中英双语）
    - 明确列出所有数据收集项（MVP：无任何主动收集）
    - 部署位置：docs/privacy-policy.md → GitHub Pages
    - 提交时填入 Partner Center

[ ] 1.2 数据收集声明（Store listing）
    - "此应用不收集任何用户数据"
    - 例外：自动更新会请求 GitHub Releases（URL 在配置中可改）
    - 异常：用户启用 TCP MCP 时，本地 127.0.0.1 监听

[ ] 1.3 启动器合规
    - 不在 Program Files 写文件
    - 不修改注册表（除 MSIX 自身所需）
    - 不启动隐藏窗口
    - 不弹未声明的广告

[ ] 1.4 应用认证（App Certification Kit）
    - 必须通过 WACK 所有测试
    - 重点：性能、稳定性、安全性、资源使用

[ ] 1.5 应用签名
    - MVP 阶段：合作伙伴中心签名（开发者账号申请）
    - 后续：EV 证书（避免 SmartScreen 警告）

[ ] 1.6 目标框架
    - Windows 10 1809+（Store 最低要求）
    - 实际测试覆盖 Win10 22H2 + Win11 23H2

[ ] 1.7 无障碍声明
    - Partner Center 要求填"supported"或"not supported"
    - MVP：声明 supported，附文档说明

================================================================
三、隐私（P0）
================================================================

[ ] 3.1 默认无遥测
    - 启动 / 退出 / 错误不上报任何服务器
    - 配置文件无 telemetry 段（v1.1 再加）

[ ] 3.2 用户输入处理
    - 终端内容不离开本机
    - capture_screen 输出只在 MCP 连接中传输（不写日志）
    - 不记录历史命令到磁盘（除非用户主动开启 history 功能）

[ ] 3.3 AI agent 权限
    - MCP 工具只能操作 attach 的 session
    - send_keys 注入时默认禁止破坏性快捷键（白名单可配置）
    - 用户在 UI 上随时可看到 attach 状态

[ ] 3.4 剪贴板
    - 读取剪贴板仅在用户主动触发时（Ctrl+V / 右键粘贴）
    - 不后台监听剪贴板

[ ] 3.5 GDPR / CCPA
    - MVP 不收集个人数据，符合"无需同意"档
    - 隐私政策明确说明

================================================================
四、安全（P0）
================================================================

[ ] 4.1 MCP server 默认 stdio
    - 默认不监听任何 TCP 端口
    - TCP 模式需用户在 UI 显式开启 + token 鉴权 + 127.0.0.1 only

[ ] 4.2 SSH 安全
    - 私钥不落盘
    - known_hosts 首次连接时确认 + 写入用户目录
    - 主机密钥变更时警告（防止中间人）

[ ] 4.3 反向 SSH tunnel
    - 默认配置为严格模式（只允许指定远端用户 / 端口）
    - 文档警告暴露风险

[ ] 4.4 配置注入防护
    - profile 命令白名单（仅允许可执行文件路径，不允许 shell 注入）
    - 配置文件 schema 校验

[ ] 4.5 依赖漏洞扫描
    - CI 跑 cargo-audit
    - PR 阶段 fail if high/critical

[ ] 4.6 自动更新源
    - 仅 HTTPS
    - 验证签名（GitHub Releases 用 minisign 签名）
