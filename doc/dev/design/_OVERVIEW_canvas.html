xsterm — Tauri 2 Terminal Emulator

跨进程架构 · frontend WebView (TS) ↔ backend tokio (Rust) · RFC 0002-revised-2 (MCP backend) · 2026-10

Frontend (5 layers)

  • • app/ 业务编排 (6 modules: shell/workspace/terminal/session/settings/mcp)
  • • ui/ 视图渲染 (5 modules + xterm.js)
  • • model/ 纯数据 (session/workspace/settings/tmux/cross-cutting)
  • • service/ zustand 镜像 (5 domains, 镜像 backend 真源)
  • • infra/ 平台适配 (tauri/store/clipboard/logger)
  • • ⭐ app/mcp/listener.ts — listen 4 类 mcp-* 事件 (退化后)

Backend (4 layers · RFC 0002-revised-2)

  • • commands/ — 9 modules × #[tauri::command], 75 IPC handlers
  • • services/ — registry/lifecycle/output/capture/transport/persistence/io/audit
  • • ⭐ services/mcp/ — MCP server (HTTP + stdio 双 transport, 12 tools)
  • • infrastructure/ — pty/ssh/tmux/session_backend/app_backend/clipboard/logging_setup
  • • models/ — 纯数据契约 (serde 派生, ⏳ RFC 0007 拆分 plan)
  • • attach_registry: try_attach / detach / check_write_permission (双层防御后端)

跨进程 wire (Tauri IPC)

  • • invoke('cmd', args) → Result<T, String> (frontend→backend 单跳, 镜像 serde)
  • • listen('event', cb) ← Unlisten (backend→frontend 推流, 11 类事件)
  • • BinaryFrame: [0xA1][0x01][sid BE 4B][len BE 4B][data] (session-output 高效编码)
  • • session-output 1 个 event → 3 订阅者 (xterm + mcp listener + state mirror)
  • • MCP emit: mcp-attach-changed / mcp-tool-called / mcp-tool-returned / mcp-server-status
  • • 禁止: frontend 直读 backend 内部字段; backend 反向依赖 frontend
